<!--
how to write updates here
- version is MAJOR.MINOR.PATCH like 2.3.1
- MAJOR when the app changes a lot or stops working the way it did before
- MINOR when new stuff gets added
- PATCH when it is only bug fixes or small polish
- newest version goes at the top
- under each version write only what applies, nothing else:
  new: Added new features
  fixed: Fixed some bugs
- use exactly those two sentences, do not name a feature, a bug, a page or a number
- skip the "new:" line when nothing was added and the "fixed:" line when nothing was fixed
- do not add summary lines or anything else under a version
- the only extra allowed is a ! after the version, like "## 3.0.8 !", for an update that people must install right away (privacy or security fixes). It installs at once and cannot be skipped.
- an update with the same first two numbers as the one people have (a patch like 3.0.7 to 3.0.8) installs quietly in the background without asking. A new minor or major version asks first.
-->
